Règles de confidentialité – Bimbalou Studio

Dernière mise à jour : 12 novembre 2026.

À quoi sert l'application

Bimbalou Studio est un outil privé utilisé uniquement par le propriétaire de la chaîne YouTube Bimbalou pour gérer cette chaîne. Il n'est pas destiné au public.

Données utilisées

Avec l'autorisation du propriétaire, l'application accède via les API YouTube (YouTube Data API et YouTube Analytics API) aux données de la seule chaîne Bimbalou : vidéos, playlists, sous-titres, miniatures, commentaires et statistiques. Elle s'en sert uniquement pour gérer cette chaîne.

Stockage et partage

Les jetons d'accès sont conservés dans le coffre sécurisé du système d'exploitation de l'ordinateur du propriétaire. Aucune donnée n'est vendue, ni partagée avec des tiers, ni utilisée à des fins publicitaires. Aucune donnée personnelle des spectateurs n'est collectée.

Respect des règles de Google

L'utilisation des informations reçues des API Google respecte le Règlement sur les données utilisateur dans les services d'API Google, y compris les exigences d'utilisation limitée. L'application utilise les services d'API YouTube et respecte les Conditions d'utilisation de YouTube et les Règles de confidentialité de Google.

Retirer l'accès

L'accès peut être retiré à tout moment depuis les autorisations du compte Google.
